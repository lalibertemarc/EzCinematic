# EzCinematic

One key for clean screenshots in WoW Forever, or for a role-play walk with nothing between you and the world: no bars, no floating names, just the music and the scenery.

`/cine` or the **Toggle cinematic mode** key binding (Key Bindings → EzCinematic):

- hides the UI (like Alt+Z), enemy and friendly nameplates, NPC names and other players' names; your own name stays as you have it
- switches sound to **Music focus**: the EzSoundMixer preset if EzSoundMixer is installed, otherwise the same default volumes built in

Press it again to put everything back exactly as it was, volumes included.
